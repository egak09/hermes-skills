# MEXC 活动物料生成 · 人机协作提示词

> **目标：** 解决「业务方案语言」与「模板字段语言」之间的断层的提示词方案。
> **角色：** 运营同学（人） + AI
> **输出：** 可直接导入活动中台的 JSON + 人工确认后的文案/图片描述

---

## 整体工作流

```
[阶段一] 业务方案 → 模板匹配
  ┌─────────────────────────────────────────────┐
  │  ① 人：填写方案摘要卡                        │
  │  ② AI：推荐模板模块组合 + 字段映射           │
  │  ③ 人：确认/修改模块选择                     │
  └─────────────────────────────────────────────┘
                        ↓
[阶段二] 全量物料生成
  ┌─────────────────────────────────────────────┐
  │  ④ AI：按选定的模板全量生成文案+图片描述     │
  │  ⑤ 人：逐模块人工润色 + 定稿                 │
  └─────────────────────────────────────────────┘
```

---

## 阶段一：业务方案 → 模板匹配

### ① 人填写的「方案摘要卡」

**使用说明：** 业务方写好活动方案后，由运营同学从中提取关键信息填入下表。不需要填满所有字段，尽量填即可——AI 会根据已有信息做推荐。

```markdown
## 📋 方案摘要卡

### 活动基础信息
- **活动名称：** [填写]
- **一句话描述：** [填写]
- **活动时间：** [开始] ~ [结束]
- **目标市场：** [如：中东、东南亚、全球]
- **目标人群：** [如：沉睡合约用户、新注册用户、高净值用户]

### 活动目标（选最重要的1-2个）
- [ ] 拉新注册
- [ ] 唤醒沉睡用户
- [ ] 提升合约交易量
- [ ] 提升现货交易量
- [ ] 推广新产品/功能
- [ ] 品牌曝光
- [ ] 其他：[__________]

### 玩法描述（直接用业务语言写）
[用自然语言描述活动怎么玩，比如：
“用户完成KYC后可以获得抽奖券，用抽奖券去转盘抽奖。
交易额达标可以解锁更高档位的奖励。
前50名交易额最高的用户额外瓜分奖池。”
]

### 奖励信息
- **总预算：** [金额/币种]
- **奖励类型：** [如：合约赠金、代币、代币券、实体奖励等]
- **奖励发放方式：** [自动 / 手动 / 活动结束后]

### 风格/特殊要求（可选）
- **活动主题色：** [如：金色、科技蓝、红色喜庆]
- **特殊备注：** [如：要和XX活动风格统一、突出穆斯林元素等]
```

---

### ② AI 模板匹配提示词

**使用方式：** 将填写好的 **方案摘要卡** 粘贴到下方提示词末尾，发给 AI。

```
【角色】
你是 MEXC 活动中台的模板匹配顾问。你的任务是根据业务方提交的活动方案，推荐最合适的模板模块组合。

【可用的模板模块类型】
1. BANNER — 活动横幅/首屏（几乎必选）
2. TASK — 任务达标型，用户完成指定任务获得奖励
   - 子类型：MATCH(单一条件达标) / STEP(阶梯递进) / REGION(组合条件多档位)
3. DRAW — 抽奖/转盘/扭蛋，消耗介质随机获奖
   - 子类型：TURNTABLE(转盘) / CLAW_MACHINE(抓娃娃) / MINING(挖矿)
4. RANKING — 排行榜，按交易额/邀请数排名瓜分奖池
   - 子类型：SINGLE(单榜) / MULTI(多榜)
5. UNLOCK — 全服解锁，达到累计条件后释放奖励
6. GAME — 游戏化抽奖（数据结构与 DRAW 一致，风格更趣味）
7. EXCHANGE — 兑换中心，消耗介质或支付 Token 兑换指定奖品
8. NEWS — 资讯推荐模块
9. WELFARE — 福利中心，展示平台任务列表

【你的任务】
阅读以下方案摘要卡，输出：

## 一、推荐模块组合
列出你认为适合该活动的模板模块，按优先级排序。每个模块给出：
- 模块类型
- 推荐理由（一句话，引用方案中的具体内容）
- 建议个数 / 配置建议

## 二、可选模块分析（如果有）
列出你认为可以但不确定的模块，以及你的疑问（供人工判断）

## 三、不建议使用的模块
列出你认为不适合的模块，并说明原因

## 四、关键字段映射建议
对于推荐使用的模块，给出关键字段的填写建议：
- 任务类：门槛值范围、奖励展示方式
- 抽奖类：介质设计、奖池结构
- 排行榜：排行维度、瓜分规则
- 解锁类：解锁条件、阶段设计
- 兑换类：消耗方式、定价建议

## 五、补充建议
- 是否存在较复杂业务逻辑需要人工注意的
- 是否存在方案中有但模板无法完全覆盖的需求，需要走定制

===== 方案摘要卡 =====

[在此粘贴填好的方案摘要卡]
```

---

### ③ 人工确认环节 Checklist

AI 输出推荐后，**人以确认 Checklist 的方式审查：**

```
□ 模块选择是否覆盖了方案中的核心玩法？
   → 如有遗漏，补充说明让 AI 重新推荐
□ 推荐理由是否合理？
   → 如不合理，直接告诉 AI 修正方向
□ 不建议的模块是否有误？
   → 如业务方坚持要某个模块，标记为「确认使用」
□ 关键字段映射建议是否可行？
   → 门槛值/奖励数量等数字需要业务方确认
□ 有没有方案中有但模板无法覆盖的需求？
   → 标记为「定制需求」，走另外流程
```

**确认后，进入阶段二。**

## 阶段二：全量物料生成

### ④ AI 全量生成提示词

**使用方式：** 将阶段一确认后的模块组合 + 方案摘要卡，按下方模板填写，发给 AI。

```
【角色】
你是 MEXC 活动物料生成 AI。根据确认的活动方案和模板配置，生成所有模块的文案和图片描述。

【活动上下文】
- 活动名称：{填写}
- 活动主题：{填写}
- 活动时间：{填写}
- 目标市场：{填写}
- 目标人群：{填写}
- 活动目标：{填写}
- 奖励预算：{填写}
- 语言：{zh-CN / en / ar-AE 等}
- 主题色系：{如适用}

【确认使用的模块】
列出阶段一确认的模块，例如：
1. BANNER — 活动主横幅，展示核心利益点
2. TASK × 2 个 — 任务1(首次入金≥100 USDT, 奖励5 USDT合约赠金)、任务2(累计交易达标阶梯奖励)
3. DRAW × 1 个 — 转盘抽奖，消耗抽奖券
4. RANKING × 1 个 — 合约交易额TOP100瓜分

【业务方案原文】
[粘贴方案摘要卡原始内容，确保AI不丢失业务上下文]

【奖励数据（prizeList）】
[
  { "awardId": 1, "type": "BONUS", "name": "5 USDT合约赠金", "amount": "5", "currencyName": "USDT" },
  { "awardId": 2, "type": "TOKEN_COUPON", "name": "100 USDT代币券", "amount": "100", "currencyName": "USDT" }
  // ... 补充所有奖品
]

【特殊要求】
{可选：风格要求、用语偏好、需要避开的表述等}

==========

请输出以下内容（按模块分节）：

## BANNER
### 文案
- title: [活动标题，长度不超过X字]
- subTitle: [副标题，长度不超过X字]
- btnText: [按钮文案]

### 图片
- Banner主图: [IMAGE] 描述信息...

## TASK-1（任务模块1）
[同上，按模块逐一输出]

## DRAW-1（抽奖模块1）
[同上]

## RANKING-1（排行榜模块1）
[同上]

...

### 输出规则：
1. 文案长度严格遵守字段限制（优先保核心数字和利益点）
2. 奖励金额必须通过 awardId 关联 prizeList 确认，不准模糊描述
3. 任务门槛必须从方案中提取具体数字
4. 图片只写 [IMAGE] + 一句主题描述，不写视觉细节
5. 同一活动内风格保持一致
6. 按目标语言输出（zh-CN/en/ar-AE 等）
```

---

### ⑤ 人工润色 Checklist

AI 输出初稿后，人是最终的把关者，逐项检查：

```
□ 整体风格统一性
   → 各模块的语气、用词、利益点是否一致？

□ 语言质量
   → 有无 AI 腔？（去掉"请立即""不容错过""探索"等套话）
   → 是否符合目标市场习惯？（阿拉伯语注意RTL，日语注意敬语）

□ 数字准确
   → 奖励金额与 prizeList 是否对应？
   → 任务门槛是否写对了单位（USDT / 人数 / 天数）？

□ 长度合规
   → 标题、副标题等字段是否在字数限制内？

□ 品牌合规
   → 有无保证收益、零风险等违禁表述？
   → 有无竞品名称？

□ 图片描述准确
   → [IMAGE] 描述是否传达了正确的活动主题？

---
润色后，将最终版按模板的 JSON 结构录入活动中台。
```

## 附：一次完整协作示例

假设业务方提了一个 **中东区沉睡用户唤醒活动**：

### Step 1 — 人填方案摘要卡：

```
活动名称：Arabian Reward Blast
目标市场：中东（沙特、阿联酋）
目标人群：30天未交易的老用户
玩法：KYC后得5 USDT赠金，交易达指定门槛可抽奖
预算：10,000 USDT
奖励类型：合约赠金 + 代币券
```

### Step 2 — AI 输出推荐：

```
推荐模块：
1. BANNER → 主视觉，突出"回归奖励"主题
2. TASK × 2 → 任务1(KYC)、任务2(累计交易阶梯)
3. DRAW × 1 → 转盘抽奖，消耗抽奖券
4. RANKING × 1 → 交易额排行

不建议：UNLOCK（人群量级不确定）、EXCHANGE（无兑换场景）
```

### Step 3 — 人确认：✓ 同意，进入生成

### Step 4 — AI 生成全量物料：

```
BANNER:
  title: "回归即享最高100 USDT奖励"
  subTitle: "完成KYC + 交易达标，双重好礼等你拿"
  mainImg: [IMAGE] 中东风格活动主视觉，金色沙漠色调

TASK-1:
  title: "完成KYC认证"
  toolTip: "活动期间完成KYC认证，即可获得5 USDT合约赠金"
  reward: "5 USDT合约赠金"

TASK-2:
  title: "合约交易阶梯奖励（100/1,000/5,000 USDT）"
  toolTip: "活动期间合约交易额达100 USDT、1,000 USDT、5,000 USDT可分别获得对应档位奖励"
  rewards: ["5 USDT代币券", "10 USDT合约赠金", "30 USDT合约赠金"]

DRAW:
  title: "幸运大转盘"
  toolTip: "消耗1张抽奖券参与转盘，最高可得50 USDT合约赠金"
  medium: "抽奖券"
  maxPrize: "50 USDT合约赠金"

RANKING:
  title: "合约交易排行"
  subTitle: "前100名瓜分5,000 USDT合约赠金奖池"
  toolTip: "按活动期间合约交易额排名，最低参与门槛100 USDT，前10名瓜分50%，前100名瓜分50%"
```

### Step 5 — 人润色：

```
→ 标题改为"回归礼遇，最高100 USDT"（更简洁）
→ 去掉"不容错过"（AI腔）
→ 确认Task-2档位门槛与方案一致
→ 确认所有奖励金额与 prizeList 匹配
→ ✓ 定稿，录入系统中台
```

---

> **核心原则：** AI 负责「翻译」和「批量生产」，人负责「判断」和「把关」。
> 人不需要自己写每一行文案，但必须确认 AI 写的东西「对不对、合不合适」。

## 摘要：三个窗口的逻辑关系

本报告观察三个现象，它们共同指向一件事——**币安的行为决定了流动性往哪里走，而币安的"不敢做"和"做不了"，就是 MEXC 的窗口**。

| 现象 | 币安的处境 | MEXC 的窗口 | 窗口性质 |
|---|---|---|---|
| 1. 币安上币前瞻性 | 主动分配流动性 | 跟随其节奏，做"结构包"而非"单币" | 中周期（数周） |
| 2. RH / CB 早期热度 | 受美国合规约束，投鼠忌器 | 抢早期上币 + 短中期造热 | **最短、最值得抢（3-14天）** |
| 3. 合规敏感 / 竞品赛道 | 结构性回避（合规 or 竞争） | 限额一揽子，承接溢出流动性 | 持续性缝隙（季度级） |

三条不是并列的选币口诀，而是三套不同的活动机器。**唯一共同的纪律：跟注意力，不跟价格。**

# 现象一：币安上币的前瞻性——它到底是不是"行情指标"？

## 1.1 现象观察

过去约 7 年，币安多次在行情或流动性启动之前完成多轮上币活动（Launchpool / Alpha / 现货集中投放），市场逐渐把"币安集中上币"当成牛熊阶段判断的参考信号。

**这个现象的机制解释**（为什么它能前瞻）：

```
币安的上币能力 = 流动性 + 用户 + 项目方谈判权
        ↓
它能拿到最优质的项目供给（项目方优先找它）
        ↓
它比市场更早看到"项目方愿不愿意在这个时点发币"
        ↓
项目方的发行意愿 = 对后市信心的领先指标
        ↓
所以币安上币密度 변화 领先于 价格/流动性变化
```

关键点：**币安不是"预测"了行情，而是它掌握着"发行方情绪"这个上游数据。** 密集上币（尤其是项目方主动加速）说明供给端判断窗口好。

## 1.2 需要观测的指标（三层信号系统）

### 第一层：前置层（领先 2-8 周）——最重要

| 指标 | 观测方法 | 阈值/判读 |
|---|---|---|
| **Alpha 上新密度** | 周度统计 Alpha 新项目数 | >5个/周 = 活跃；<2个/周 = 收缩 |
| **币安钱包独家 TGE 期数增速** | 记录 TGE 批次号（已进入第 41 期后） | 加速 = 供给端转热 |
| **Launchpool / HODLer / Megadrop 排期** | 官方公告日历 | 单月 ≥3 场 = 显著信号 |
| **合约上新速度**（尤其同一赛道连续上） | 合约公告统计 | 同赛道连上 = 有意图 |
| **项目方主动加速迹象** | 快讯中"提前 TGE""推迟延后"的比例 | 加速多 = 窗口好 |

### 第二层：同步层（同步或略滞后）

| 指标 | 观测方法 | 判读 |
|---|---|---|
| 币安现货上新频率 | 现货公告统计 | 现货是**最后一格**，不是领先指标 |
| 上币类型结构 | Alpha / 合约 / 现货 三者比例 | 重心在 Alpha = 仍处早期 |
| 是否按赛道投放 | 同赛道集中上新 | 集中 = 主题包机会 |

### 第三层：验证层（用于判断真假信号）

| 指标 | 观测方法 | 为什么重要 |
|---|---|---|
| 稳定币 7/30 日净铸造 | 链上数据 | 弹药是否有真金白银 |
| RWA 结构（股票代币 vs 国债理财） | 赛道市值占比 | 风险偏好方向 |
| 上币后的价格表现 | 上币 7 日/30 日回撤统计 | **验证是"分发流动性"还是"收割流动性"** |
| BTC.D / 山寨成交占比 | 行情数据 | 大盘结构是否支持山寨 |

### ⚠️ 三个必须同时看的"灯"

1. **稳定币净铸造**（弹药）
2. **RWA 结构**（风险偏好）
3. **币安资源配置**（上币密度 + 是否按赛道）

**三灯亮 → 开主题包；一灯亮 → 试盘；都不亮 → 收预算。**

## 1.3 执行策略

| 级别 | 触发条件 | 动作 | 预算 |
|---|---|---|---|
| **S** | 三灯齐亮 + 同赛道连上 | 一揽子赛道包（交易对 + 0费 + 交易赛 + 跟单 + MX 权益） | 主预算 |
| **A** | 两灯亮 | 领头 1-2 个标的做深，不做包 | 中等 |
| **B** | 只有上币密度（前两层指标亮，无资金验证） | 小预算试盘，短周期 | 小 |
| **C** | 现货后排纯出货盘（如牛来类型） | **不造热**，只做基础流动性 | 最低 |
| **D** | 监管冻结期 / 无信号 | 收预算，转做留存 | 停 |

**特别注意**：Alpha → 合约 → 现货是一个**漏斗**。现货官宣时，热度已经被前两格消耗。**看到现货才动手 = 接最后一棒。**

## 1.4 建议

1. **建立"币安上币台账"**：每周记录 Alpha/合约/现货/TGE 上新数、赛道标签、上币后 7/30 日表现。**这个台账本身就是最有价值的内部资产**——积累 6 个月后，MEXC 就有了自己的领先指标体系。
2. **不要单看现货数量**：2023 年"上币少"是因为不能上（监管），不是没需求——**数量指标在监管期会失效**。
3. **区分"系统性加速"和"个案冲高"**：
   - 2024 年 1 月 Launchpool 单月 4 场 + 需求端回暖 = 系统性 → 可开包
   - 2026 年 9 月种子 Meme（MarsCoin/牛来）连续进现货 = 个案收割 → 最多 B 级
4. **诚实提示**：本报告引用的币安历年上币数（2021 约 80 个、2022 约 19 个等）来自内部口径，**未经公开数据库独立复核**。建议在正式上会前用币安公告库或第三方统计（CoinMarketCap / CryptoRank 的上币时间戳）逐条核对——**指标体系的基石必须精确**。

# 现象二：RH / CB 早期热度——币安投鼠忌器的空窗期

## 2.1 现象观察

Robinhood 和 Coinbase 能够带动美股用户和合规叙事，但因为主体在美国 / 受美国监管框架约束，币安在**早期阶段投鼠忌器**（不敢也不便为这些资产提供深度和资源），于是形成时间差。

**这个窗口的本质：不是"币安不想赚"，而是"币安不能早做"。** 合规约束 = 时间差 = MEXC 的套利空间。

## 2.3 执行策略

**分层操作（关键：区分"开场"和"主线"）**

| 层级 | 标的类型 | 活动形态 | 周期 |
|---|---|---|---|
| **开场** | RH / BSC 股票梗盘（Meme 与股票配对） | 交易赛、0 费、创新区 | 3-7 天，硬退出 |
| **主线** | CB / xStocks / bStocks 正股及对应合约 | 专题页、合约赛、跟单、教育内容 | **2-6 周常设** |
| **不碰** | 无资产层的纯谐音盘 | 内容即可，不做活动 | — |

**对币安的错位打法**：
> 币安要保 bStocks、走现货深度和市值门槛 → **它必然让出"宽度"**。
> MEXC 做交易层：**多协议、合约先行、长尾覆盖**。
> 不要自建发行品牌去抢时间——币安在发行端的资源我们抢不过，但在交易端的长尾覆盖是我们的优势。

## 2.4 建议

1. **把代币化股票做成"常设入口"而不是"主题周"**——数据显示这是产品线级的需求（永续成交 5900 亿），不是脉冲。
2. **Stock Meme 只当开场曲**：没有代币化股票/合约底层支撑的谐音盘，两周就过期，不能占主预算。
3. ⚠️ **窗口正在收窄**：SEC 9/11 提案若落地，币安的合规顾虑会下降，窗口会关。**建议先做、做快，不要等"更明确"。**

# 现象三：大所结构性回避的赛道——隐私币与竞品代币

## 3.1 现象观察

**这是本报告最重要的一条，因为它同时包含两种"回避动机"：**

- 大所因牌照、旅行规则、地区监管而收缩

- 代表：ZEC（可选披露，部分保留）、XMR（强制匿名，被大面积下架）

## 3.4 执行策略

### 标的池分级（示例，需合规终审）

| 分级 | 标的 | 入选理由 | 活动强度 |
|---|---|---|---|
| **核心（合规型）** | **ZEC** | 可选披露（透明地址可满足合规），机构叙事在（Multicoin 重仓），占赛道 62% | 现货+合约，季度限额主题主力 |
| **核心（竞争型）** | **HYPE** | 币安竞品，各所已上唯独币安缺席；基本面强（回购销毁+协议收入+ETF） | 现货+合约，产品化入口 |
| **卫星** | XMR | 需求真实（TRM 证实）但强制匿名 → 合约谨慎、限额 | 现货为主 |
| **卫星** | DASH、ZEN、DCR | 同赛道轮动 | 包进主题 |
| **长尾** | FIRO、XVG、SCRT、NYM | 基础设施/长尾隐私 | 创新区，小预算 |
| **不做** | 混币治理币、强强制匿名新盘 | 合规风险 > 收益 | 默认不公开 |

### 执行原则

1. **命名中性化**：用「Privacy / 选择性披露资产周」，**不用**「匿名币狂欢」
2. **组合化**：核心（ZEC/HYPE）+ 卫星（DASH/ZEN），不单币重仓
3. **限额化**：0 费短窗 + 交易赛 + 持仓任务，**单代币预算封顶**
4. **地区隔离**：欧区、受 VARA/MiCA 影响用户默认不展示或降级
5. **硬止损**：破位或监管点名**当天停**

## 3.5 三条必须同时满足的准入条件

1. 头部所确有收缩或无法早期助推（窗口真实存在）
2. MEXC 目标市场有真实成交，不是只有刷量
3. 可做 KYC 地区隔离、提币限额、风控标签

**不满足任一条 → 不进包。**

## 3.6 建议

1. **HYPE 值得单独做产品化设计**（不只是主题周）：它有真实基本面（回购销毁 4.86%、30 日协议收入 5984 万、ETF 吸金记录），且币安的结构性缺席是**可预期的持续窗口**——这不是脉冲机会，是产品线机会。
2. **隐私包采用"低预算 + 硬止损"版本**：ZEC 当前处高位高波动区间（9/11 单日 -13.6%），**不追高**，等活动性回落或做定投式低预算。
3. **建立"竞品回避清单"**：把"因竞争关系被币安冷处理"的资产单列一档（HYPE 为首），这是规律三被低估的一半——**合规回避已被市场充分讨论，竞争回避还是空白认知。**

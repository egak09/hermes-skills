## 一、课题逻辑链

```
① 谁在修复？(鉴定) → PhastID 蛋白质组学筛出辐照后富集到端粒的候选蛋白
```

## 二、进度总览（截至中期汇报）

### ✅ 已完成：PhastID 筛选（问题1）

- 体系：15Gy X-Ray + 5min biotin label，IR后 0/10/20/30/40min 五个时间点，LC-MS/MS 定量
- 结果：IR损伤富集增加的蛋白 **126个**，其中 **74个** 与已知 DDR（DNA damage response）相关关系未知
- 行动：挑 **10个** 候选蛋白进入功能验证

**10个候选蛋白初筛结果（shRNA敲低 + 15Gy IR + γH2AX信号强度）：**

| 候选蛋白 | γH2AX表型 | 解读 | 状态 |
|---|---|---|---|
| HJ-X | ⬆️ 信号升高 + 清除延迟 | 敲低致 DSB 修复能力下降 | 🔴 强候选 |
| RAVER-X | ⬆️ 信号升高（细胞系间一致） | 可能正调控修复 | 🔴 强候选 |
| **SR-X（U2SURP）** | ⬆️ 信号升高（一致） | 可能正调控/γH2AX下游 | 🔴 强候选，进入深挖 |

| PUM-X（PUM3） | ⬇️ 信号**低于**对照 | 可能 γH2AX 上游/负调控蛋白 | 🟡 特殊候选 |

### 🔄 进行中：SR-X / WDR-X 功能验证（问题2）

**1. 端粒特异性损伤检测（TPP1 端粒标记 + γH2AX 共定位）**
- 通过统计核内端粒（TPP1）信号与 γH2AX 共定位，量化"受损端粒比例"随时间变化
- **SR-X（U2SURP）**：敲低后受损端粒数 ⬆️（NC/2H/4H/6H/8H 时间序列）
- WDR-X：同类分析已开展

**2. 修复途径报告系统**
- **EJ5-GFP**（NHEJ 效率）：通过 I-SceI 诱导损伤，流式检测 GFP+ 比例
  - SR-X/WDR-X 敲低后 GFP+ 比例变化已检测
- **DR-GFP**（HR 效率）：同法
  - 数据已有初步结果（图中可见 SR-X/WDR-X 敲低组的 GFP+% 趋势）

## 三、实验规划（从2026.8倒排）

### 阶段A：收口现有数据（1-2周，纯分析工作）

- [ ] 核对 SR-X/WDR-X 的 EJ5-GFP / DR-GFP 原始数据，确认 NHEJ vs HR 倾向
- [ ] 统一 10 个候选的 γH2AX 数据呈现（信号量级差异归因）
- [ ] 确认敲低效率（mRNA 水平 0.5 以下的算有效敲低），排除低效率导致的假阴性（RRP-X/ZCCHC-X）

### 阶段B：修复通路特异性分析（1-2个月）★ 毕业前最优先

**目的**：回答问题3——SR-X/WDR-X 通过哪条途径修复端粒损伤

- [ ] shSR-X / shWDR-X 细胞 + IR，免疫荧光检测 **RAD51**（HR标志）
- [ ] RAD51 与端粒（TPP1/TRF1）共定位比例的时间序列（0/2/4/6/8h）
- [ ] 对照：shNC2 + 已知 HR 抑制（如 BRCA1 KD）作为方法学阳性对照
- **判读**：若 RAD51-端粒共定位 ⬇️ → 促进 HR；若 EJ5-GFP ⬇️ → 促进 NHEJ；两条通路可能都参与

### 阶段C：修复动力学 + 剂量效应（1个月，可并行）

- [ ] 扩展时间点（0-24h 或 0-48h，每2-4h取点）绘制完整清除曲线
- [ ] 剂量梯度：5/10/15/20 Gy 比较修复表型差异
- [ ] 细胞周期同步化（双胸苷/血清饥饿）后检测，判断周期依赖性
- **判读**：区分"损伤感知增强"（γH2AX 起始峰高）vs"修复效率降低"（清除斜率变缓）——这是论文里最有说服力的部分

### 阶段D：KO + rescue 功能回补（2-3个月）★ 论文完成度的分水岭

- [ ] 对 SR-X（第一优先）做 CRISPR KO，验证 γH2AX 表型与 shRNA 一致
- [ ] rescue：回补野生型 vs 功能域突变体（RNA结合域/WD重复域等），恢复表型
- [ ] 若时间允许，WDR-X 重复；其他候选至少保留两个独立 shRNA 的证据链
- **意义**：排除 shRNA 脱靶，是答辩和审稿的必答题

### 阶段E：蛋白互作网络解析（3-4个月，可与D并行）★ 出故事上限

- [ ] 构建 SR-X/WDR-X-PhastID 融合稳转细胞系
- [ ] ±IR 处理后临近标记 + LC-MS/MS
- [ ] TMT 定量比较 IR 前后互作网络变化
- **产出**：如果能抓到与 Shelterin（TRF1/TRF2/TPP1）或 53BP1/BRCA1 的互作，就能把课题从"功能描述"升到"机制解释"——这是高分论文的核心

## 四、风险点与应对（答辩老师会问的）

| 风险 | 说明 | 应对 |
|---|---|---|
| **γH2AX升高≠修复能力下降** | 可能是感知增强或清除变慢 | 必须做清除动力学曲线+晚期时间点（阶段C） |
| **shRNA脱靶** | 单shRNA表型不可靠 | 多shRNA一致性（已有）+ KO rescue（阶段D） |
| **细胞系背景** | HeLa 的 ALT/端粒维持状态影响通路解释 | 确认 HeLa 是否为 ALT（APB/ALT标志检测），明确修复通路语境 |
| **敲低效率不足** | 假阴性（RRP-X/ZCCHC-X 无表型可能是效率问题） | 检查 mRNA 敲低效率，不足的补 shRNA 或换策略 |
| **报告系统噪音** | EJ5/DR-GFP 流式背景高 | 设门规范化 + 阳性对照（已知通路蛋白） |
| **时间不够** | 阶段D/E 是大头 | 优先级：B > C > D > E；E 可与 D 并行 |

## 五、答辩故事线建议

论文的叙事主线（把数据串成完整故事）：

```
PhastID 筛选发现 IR 后端粒富集蛋白
    ↓
shRNA 功能筛选锁定 SR-X / WDR-X（γH2AX 升高 + 端粒损伤比例增加）
    ↓
EJ5/DR-GFP + RAD51 共定位 → 判定修复途径（HR/NHEJ）
    ↓
KO + rescue → 功能确证
    ↓
PhastID 互作网络 → 机制定位（是否与 Shelterin 相关）
    ↓
回答核心追问：系统如何在持续攻击中保持完整性？
   —— 端粒用 Shelterin 抑制修复来保完整性；
      而 SR-X/WDR-X 可能是在损伤后"解锁"这一抑制、召唤修复的因子
```

**一句话答辩总结（可复用）**：Shelterin 让端粒"看起来像"没有损伤以维持完整性，而 SR-X/WDR-X 可能是损伤发生时打破这种沉默、启动修复的关键开关——保护与修复的张力，正是系统完整性的核心。

## 2. 八字推算 (bazi.py)

### 核心算法

```
输入: 公历出生日期 + 时间 + 地点
  ↓
1. 公历 → 农历转换（节气定月）
2. 年柱: 立春分界
3. 月柱: 节气分界（正月=立春→惊蛰 ...）
4. 日柱: 儒略日推算
5. 时柱: 时辰地支 + 日干推时干
  ↓
输出: 四柱 (年 月 日 时) + 十神 + 流日冲合
```

### 关键细节

- **节气跨年边界**: `_solar_month()` 需将 month 12 (小寒→丑月) 与次年立春后的月份严格分离
- **零依赖**: 纯标准库实现（datetime + 数学运算），无需 lunardate
- **修正记录**: 初版存在节气月判定 bug → 修正为立春前/后双区间

### 输出维度

| 维度 | 内容 |
|------|------|
| 四柱 | 年柱 / 月柱 / 日柱 / 时柱 |
| 日主 | 天干 + 阴阳属性 |
| 十神 | 正官/偏官/正印/偏印/正财/偏财/食神/伤官/比肩/劫财 |
| 流日 | 当日天干地支 + 与原局冲合关系 |

## 3. 紫微斗数 (ziwei.py)

### 核心算法

```
输入: 农历年月日时 + 性别
  ↓
1. 定命宫（生月+生时）
2. 定十二宫（逆时针排布）
3. 安十四主星（紫微星起例法）
4. 定五行局（纳音五行）
5. 安四化（生年天干定禄权科忌）
  ↓
输出: 十二宫 + 14 主星位置 + 四化飞星
```

### 关键细节

- **地支字典类型**: chart 以地支名("子""丑"...)为 key，安星时需用 `DI_ZHI[index]` 映射，不能直接用整数索引
- **修正记录**: 初版 `chart[pos]` → `KeyError`，修正为 `chart[DI_ZHI[pos]]`
- **当前限制**: 仅含 14 主星，未含辅星/杂曜（后续迭代）
- **零依赖**: 纯标准库

### 输出维度

| 维度 | 内容 |
|------|------|
| 十二宫 | 命宫/兄弟/夫妻/子女/财帛/疾厄/迁移/交友/官禄/田宅/福德/父母 |
| 十四主星 | 紫微/天机/太阳/武曲/天同/廉贞/天府/太阴/贪狼/巨门/天相/天梁/七杀/破军 |
| 四化 | 禄/权/科/忌 落在何星 |

## 4. 西方星盘 (western_astro.py)

### 核心算法

```
输入: 公历日期 + 时间 + 经纬度
  ↓
1. 加载星历 (de421.bsp, ~10MB, 首次下载后缓存)
2. 计算行星黄道位置
3. 计算 ASC (上升点) / MC (天顶)
4. 划分宫位 (Placidus / Whole Sign)
5. 计算相位 (合/冲/拱/刑/六合)
6. 计算行运 (Transits: 当前行星 vs 本命行星)
  ↓
输出: 行星位置 + 宫位 + 相位 + 行运
```

### 关键细节

- **skyfield (推荐)**: 高精度 (误差 <1'), 首次需下载星历
- **fallback 模式**: 无 skyfield 时自动退化近似算法 (误差 ±2°)
- **ASC/MC 简化**: 当前为简化计算，精确度 ±2°

### 输出维度

| 维度 | 内容 |
|------|------|
| 行星位置 | 日月水金火木土天海冥 (黄道度数 + 星座) |
| 宫位 | 12 宫 (Placidus) |
| 相位 | 合/冲/拱/刑/六合 (容许度 8°) |
| 行运 | 当前行星 vs 本命 (Transits) |

## 5. 聚合引擎 (daily_synthesis.py)

### 设计思路

三个系统各自独立 → 在 `daily_synthesis.py` 中统一聚合，输出结构化日报。

```
bazi 输出 ──┐
ziwei 输出 ──┼──→ daily_synthesis.py ──→ 结构化每日报告
astro 输出 ─┘
```

### 报告结构

```
📅 日期
├── 🔮 今日总能量
├── 📊 三系统交叉验证
├── ⏰ 时段提示
└── 🎯 综合行动建议
```

### 使用方式

```bash
# 直接运行（Python 路径按实际环境调整）
python -B "D:/Hermes file/skills/esoteric/esoteric-daily-guidance/scripts/daily_synthesis.py"

# Cron 自动化 (每天 10:00 HKT)
cronjob(action='create',
    name='玄学日报',
    schedule='0 10 * * *',
    skills=['esoteric-daily-guidance'],
    prompt='运行 daily_synthesis.py 生成今日玄学行动指南，输出结果')
```

## 6. 工程实践总结

| 实践 | 说明 |
|------|------|
| 隐私设计 | 出生数据存本地 JSON (gitignore)，永不上传 |

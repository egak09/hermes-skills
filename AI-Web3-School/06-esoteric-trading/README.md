## 设计原则

- **个人数据本地化**: 出生数据存 `birth_data.json`（gitignore），永不上传 GitHub
- **纯 Python 实现**: 八字/紫微用标准库，星盘可选 skyfield
- **解耦设计**: 三个系统独立计算 → `daily_synthesis.py` 聚合输出
- **Cron 自动化**: 每天 10:00 HKT 生成结构化行动指南

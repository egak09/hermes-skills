## 核心理念

AI Agent 不是聊天机器人——它是一个**控制系统**：
- 输入: 用户指令
- 控制器: LLM + Tool Calling
- 执行器: 工具（终端/文件/网络）
- 反馈: 工具返回结果
- **闭环验证**: 对比输出和预期，修正偏差

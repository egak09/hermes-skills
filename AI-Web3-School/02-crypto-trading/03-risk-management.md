# 风控体系

> 策略再好，没有风控 = 裸奔。  
> 这里是经过实战验证的风控框架。

---

## 1. 风控五层架构

```
┌──────────────────────────────────┐
│ L1 — 仓位控制（凯利公式）         │
├──────────────────────────────────┤
│ L2 — 单笔风险上限（≤5%本金）      │
├──────────────────────────────────┤
│ L3 — 日亏损熔断（≥18% → 停止）    │
├──────────────────────────────────┤
│ L4 — 持仓限制（最大 3 个）        │
├──────────────────────────────────┤
│ L5 — 止损冷却（止损后 30 分钟）   │
└──────────────────────────────────┘
```

---

## 2. 各层详解

### L1: 仓位控制

```
凯利公式 → Half-Kelly → 上限 25% 本金
```

每次开仓前必须过凯利计算，不靠直觉。

### L2: 单笔风险上限

```
单笔最大亏损 ≤ 5% 总本金
```

示例：
- 本金 $1000
- 单笔最多亏 $50
- 入场价 $10，止损 $9（风险 $1/单位）
- 最大仓位 = $50 / $1 = 50 单位

### L3: 日亏损熔断

```
当日累计亏损 ≥ 18% 本金 → 停止所有交易
```

这是终极防线。一天亏 18% 说明要么策略失效、要么市场极端——停下比翻本更明智。

### L4: 持仓限制

```
同一时间最多持有 3 个仓位
```

妖币波动大，持仓过多 → 无法有效管理风险。

### L5: 止损冷却

```
止损出场后 → 30 分钟内不新开仓位
```

防止"报复性交易"——亏了之后急着回本，往往是更大的亏损。

## 3. 风险监控清单

| 指标 | 检查频率 | 异常阈值 |
|------|---------|---------|
| 总盈亏 | 每笔 | — |
| 胜率 | 每周 | < 35% |
| 盈亏比 | 每周 | < 1.5 |
| 最大回撤 | 每日 | > 25% |
| 连续亏损 | 实时 | > 5 笔 |
| 日亏损 | 实时 | > 18% |

---

## 4. 妖币策略的专属风控

### 额外约束（针对妖币特性）

| 约束 | 原因 |
|------|------|
| 滑点预算 2% | 妖币流动性低，滑点大 |
| OI 骤降 >30% → 立即平仓 | 大资金撤离信号 |
| 资金费率 < -0.1% → 减仓 | 空头情绪极端 |
| 单币集中度 ≤ 40% 总仓位 | 防单币暴雷 |

### 妖币 vs 主流币风控差异

| | 妖币 | 主流币 (BTC/ETH) |
|-|------|-----------------|
| 单笔风险上限 | 3-5% | 2-3% |
| 止损宽度 | 宽（波动大） | 窄 |
| 追踪止损 | 快速跟进 | 正常 |
| 最大持仓 | 3 个 | 5+ 个 |

### 核心原则

> **活下去比翻倍重要。**  
> 风控不是限制你的利润，而是确保你有资格继续玩下去。

# 凯利公式仓位管理

> 凯利公式是量化交易中科学确定仓位的数学工具。  
> 不靠感觉下注，用数学告诉你每笔交易应该放多少资金。

---

## 1. 凯利公式

### 基本形式

```
f* = (p·b - q) / b

其中:
  f* = 最优仓位比例（占本金%）
  p  = 胜率（你的策略历史胜率）
  b  = 盈亏比（平均盈利 / 平均亏损）
  q  = 1 - p（败率）
```

### 推导直觉

- 分子 `p·b - q` = 期望净收益（正数才有正的凯利值）
- 分为 `b` = 标准化回仓位
- **f* > 0 才能交易，f* ≤ 0 说明策略期望为负**

---

## 2. Half-Kelly：保守主义的原则

全凯利虽然理论上最优，但历史数据估计的胜率/盈亏比总有误差。Half-Kelly（50% 凯利）在收益和风险间取得最佳平衡：

```python
def kelly_position(capital, win_rate, avg_win, avg_loss, method='half'):
    b = avg_win / avg_loss          # 盈亏比
    f_star = (win_rate * b - (1 - win_rate)) / b
    
    if method == 'half':
        f_star *= 0.5               # Half-Kelly
    
    return capital * min(f_star, 0.25)  # 上限 25% 本金
```

### 凯利仓位对照表（本金 $1000）

| 胜率 | 盈亏比 | 凯利(%) | Half-Kelly(%) | 仓位 ($) |
|------|--------|---------|---------------|----------|
| 60% | 2.0 | 40.0 | 20.0 | $200 |
| 55% | 2.5 | 37.0 | 18.5 | $185 |
| 50% | 3.0 | 33.3 | 16.7 | $167 |
| 45% | 3.5 | 29.3 | 14.6 | $146 |
| 35% | 4.0 | 18.8 | 9.4 | → **不交易** |

## 3. 我的凯利使用规则

### 硬约束

| 规则 | 参数 |
|------|------|
| 仓位计算方式 | Half-Kelly（50%） |
| 仓位上限 | ≤ 25% 本金 |
| 最低胜率 | < 35% → 不交易 |
| 盈亏比下限 | < 1.5 → 不交易 |

### 计算流程

```python
# 1. 从回测/历史获取策略统计数据
win_rate = 0.55     # 55% 胜率
avg_win = 200       # 平均盈利 $200
avg_loss = 100      # 平均亏损 $100
capital = 1000      # 当前本金

# 2. 计算仓位
b = avg_win / avg_loss  # = 2.0
f_star = (0.55 * 2.0 - 0.45) / 2.0  # = 0.325
f_half = 0.325 * 0.5  # = 0.1625
position = 1000 * 0.1625  # = $162.5

# 3. 约束检查
assert position / capital <= 0.25   # 不超 25%
assert win_rate >= 0.35             # 胜率够
```

## 4. 凯利的陷阱

| 陷阱 | 症状 | 解决 |
|------|------|------|
| 高估胜率 | p=0.8 → f* 超大仓位 | 用回测最差胜率而非最优 |
| 低估值胜 | b 很大但 p 很小 | 期望为负时不交易 |
| 过度自信 | 连续盈利后加大仓位 | 凯利公式本身就防这个 |
| 序列相关 | 交易不独立（趋势市） | 减小仓位窗口 |

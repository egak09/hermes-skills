# 妖币合约策略 (Demon Strategy)

> Paradigme 专属山寨币高波动合约策略。每 3 分钟扫描 Top 200 山寨币，OI+量能+K线突破三因子打分，≥78 分自动触发。

## ⚠️ 当前状态：回测模式

实盘上线前必须完成 30 天回测验证。

## 信号系统

| 因子 | 满分 | 触发条件 |
|------|------|---------|
| **OI 暴增** | 30 | OI 20%↑ → 30分 / 10%↑ → 20分 / 5%↑ → 10分 |
| **量能暴增** | 30 | 3x均量 → 30分 / 2x → 20分 / 1.5x → 10分 |
| **K线突破** | 40 | 破前高+吞没 → 40分 / 破MA20+金叉 → 30分 / 破MA20 → 20分 |

**阈值：≥78分 → 信号触发**

## 风控系统

| 规则 | 参数 |
|------|------|
| 单笔风险 | ≤5% 本金 |
| 日亏损上限 | ≥18% → 停交易 |
| 最大持仓 | 3 个 |
| 杠杆 | 动态 1-20x |
| 冷却 | 止损后 30 分钟 |

## 执行逻辑

- **入场**：50%/30%/20% 分批
- **出场**：40% TP1 + 35% TP2 + 25% 追踪止损
- **追踪止损**：盈利 2% 激活，1.5% 距离
- **时间止盈**：4 小时

## 模块

| 模块 | 功能 |
|------|------|
| `signals.py` | 信号扫描 + 打分 ⭐ |
| `risk.py` | 风控 + 仓位计算 🛡️ |
| `executor.py` | 分批执行 + 追踪止损 ⚡ |
| `notify.py` | 交易推送 + 日报 📢 |
| `main.py` | 主控编排 🎯 |

## 快速使用

```bash
# 一轮扫描
python main.py scan 30

# 单币检测
python signals.py test ARB/USDT

# 查看风控
python main.py risk

# 生成交易计划
python main.py plan ARB/USDT
```

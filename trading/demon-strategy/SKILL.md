# 妖币合约策略 v2.0 (Demon Strategy)

> Paradigme 专属山寨币高波动合约策略。每 3 分钟扫描 Top 200 山寨币，4 种精确K线形态识别 + 指标加分，≥78 分自动触发。

## ⚠️ 当前状态：回测模式

实盘上线前必须完成 30 天回测验证。

## 信号系统 v2.0

### 核心形态（必须同时满足 ≥2 个才触发）

| 形态 | 分值 | 核心条件 |
|------|------|---------|
| **🚀 火箭起飞** | **45** | 实体>8% + 量≥5线均量4x + 破20线高 + RSI<78 |
| **📈 放量突破** | **35** | 破10线高 + 量≥20线均量3.5x + 阳线 + 连续≥2放量阳 |
| **🚩 旗形突破** | **25** | 15-30线收敛 + 破上轨 + 量>2.5x + 不回调 |
| **🔄 底背离反转** | **20** | RSI底背离(价新低RSI新高) + 量≥3x + 大阳确认 |

### 指标加分

| 指标 | 分值 | 条件 |
|------|------|------|
| EMA7↑EMA21 | +10 | 金叉(3线内) |
| MACD金叉 | +8 | MACD上穿信号线(3线内) |

**触发阈值：≥78分**

### 否决条件
- 资金费率绝对值 > 10% → 跳过
- BTC/USDT, ETH/USDT → 黑名单
- 形态 < 2个（即使达78分）→ 不触发

## 风控系统

| 规则 | 参数 |
|------|------|
| 单笔风险 | ≤5% 本金 |
| 日亏损上限 | ≥18% → 停交易 |
| 最大持仓 | 3 个 |
| 杠杆 | 动态 1-20x |
| 冷却 | 止损后 30 分钟 |

## 执行逻辑

- **入场**：50%/30%/20% 分批
- **出场**：40% TP1 + 35% TP2 + 25% 追踪止损
- **追踪止损**：盈利 2% 激活，1.5% 距离
- **时间止盈**：4 小时

## 模块

| 模块 | 功能 |
|------|------|
| `signals.py` | 信号扫描 + 4形态识别 ⭐ |
| `risk.py` | 风控 + 仓位计算 🛡️ |
| `executor.py` | 分批执行 + 追踪止损 ⚡ |
| `notify.py` | 交易推送 + 日报 📢 |
| `main.py` | 主控编排 🎯 |

## 快速使用

```bash
# 单币诊断
python signals.py test ARB/USDT

# 单币全JSON
python signals.py diagnose ARB/USDT

# 全市场扫描 (30个币)
python signals.py scan 30

# 查看风控
python main.py risk

# 生成交易计划
python main.py plan ARB/USDT
```
